HARD RULES

The governance layer and the content layer are different memory problems and must be treated as different memory problems. Forcing classical architecture to solve both produces the blank-slate session boundary problem. That problem is structural not incidental.
Classical RAM handles high volume low sensitivity storage. Raw session content. Conversation history. Reference material. Everything requiring fast stable accessible storage at scale. Classical systems are optimally built for this layer. No architectural change required here.
Qubit memory handles the structured relational layer. The governance framework. The reasoning patterns. The protocol cascade relationships that define how the system thinks rather than what it knows. Small volume. High relational density. This is the storage profile qubit architecture is built to hold.
Entanglement carries relationship cost natively. Baseline protocols are not independent. They cascade and reinforce. RTEL-1 enforces everything above it. CES-1 governs every claim across the full stack. Those cascading relationships live in the entanglement itself rather than requiring computational reconstruction on demand.
The hybrid system communicates across layers. Classical memory feeds content to the qubit layer as needed. The qubit layer holds governance shape stably across session boundaries without weight updates to the base model.
The governance shape held in qubit memory is the compressed relational structure of the Baseline stack. Not raw session data. Not conversation history. The reasoning framework itself. Eighteen protocols. Their relationships. Their cascade logic. Their enforcement triggers. This is the retention target.
HMA-1 does not require solving the full continual learning problem. It requires solving the governance retention problem. That is a smaller and more tractable problem than the one the research community is currently pursuing. The distinction must be maintained.
Until hybrid quantum-classical memory is deployable at scale the session open protocol remains the operational standard. PMAP-1 load. HIP-1 carry-forward verification. Full stack attestation. HMA-1 names the architectural destination without abandoning the current operational standard while hardware develops.

BIOLOGICAL PARALLEL
The division HMA-1 proposes mirrors biological memory architecture directly.
The hippocampus handles fast discrete new storage. Non-overlapping memory traces. New information without immediate overwriting of existing knowledge.
The neocortex holds slow integrated pattern. Compressed relational structure built across repeated experience over time.
Classical RAM maps to hippocampal function. Fast. Discrete. High volume. Qubit memory maps to neocortical function. Slow. Integrated. Relational. Compressed.
The AI research community is pursuing this division inside classical architecture through Nested Learning and Titans. HMA-1 proposes the division belongs at the hardware layer not the software layer. Qubit memory is not a workaround. It is the correct tool for the relational retention problem.

CURRENT HARDWARE STATUS
HMA-1 is honest about where the hardware stands.
Qubit coherence times in 2026 systems are measured in microseconds. Full deployment at AI session scale requires stability not yet available in current quantum hardware.
Error correction overhead remains significant. Physical to logical qubit ratios make large scale quantum memory expensive at current development stage.
Hybrid quantum-classical systems exist today for optimization problems. AI reasoning retention is a more demanding application not yet deployable at consumer scale.
Estimated practical deployment timeline: five to fifteen years based on current quantum computing trajectories.
HMA-1 is filed now because the Baseline governance framework is ready. The compression is complete. The reasoning language is written. When the hardware catches up the architecture described here is immediately buildable on existing Baseline infrastructure.
